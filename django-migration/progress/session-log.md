## שיחה #1 - 2026-01-29

### נושא
סקירת פרויקט ותכנון מיגרציה

### מה נעשה
1. **סקירה מקיפה** של פרויקט מאירים הקיים:
   - ארכיטקטורה: Node.js/Express backend, React frontend
   - 35 מודלים, 27 controllers
   - סורקים: iPlan, Mavat, 13 סורקי עצים
   - תשתית: AWS ECS, Docker, GitHub Actions

2. **דיון על אסטרטגיית מיגרציה:**
   - הוחלט: אפיון מהקוד + בנייה מחדש (לא המרה אוטומטית)
   - יתרונות Django: Admin מובנה, GeoDjango, Celery

3. **יצירת מבנה תיעוד:**
   - `django-migration/` - תיקייה ראשית
   - `PLAN.md` - תכנית עבודה מפורטת
   - `CONTEXT.md` - סיכום להעברה בין שיחות
   - `progress/session-log.md` - קובץ זה

### החלטות
| נושא | החלטה |
|------|--------|
| גישת מיגרציה | אפיון + שכתוב (לא המרה) |
| מבנה תיעוד | Markdown בתוך הרפו |
| **מיקום רפו** | **רפו נפרד בשם `kav-adom`** |
| **שם הפרויקט** | **"קו אדום" / kav-adom** |
| **Frontend** | **Django templates + HTMX + Alpine.js** |
| **תאימות API** | **לא נדרשת - לעצב מחדש** |

### דיונים נוספים
- **HTMX**: סקירה מפורטת - ספרייה יציבה (~42K stars), מתאימה מצוין ל-Django
- **R Shiny**: נדון בקצרה, הוחלט לא לכלול כרגע

### הפעולה הבאה
1. ליצור רפו חדש `kav-adom` ב-GitHub
2. לפתוח שיחה חדשה עם הרפו החדש
3. להתחיל חילוץ DB Schema מהקוד של מאירים
